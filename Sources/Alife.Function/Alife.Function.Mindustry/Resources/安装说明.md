# Mindustry 陪玩

角色通过游戏侧接口查看关卡、波次和核心库存，并指挥一台独立的同队建造单位。游戏按正常规则建造并扣除核心物资。普通模式直接在玩家开的桌面客户端房间中运行。

## Windows 快速开始

1. 从 [官方发布页](https://github.com/Anuken/Mindustry/releases/tag/v160.8) 下载 Windows 桌面版并解压。新版便携包根目录应包含 `Mindustry.exe`、`jre` 和 `mods`。单人、战役和玩家自己开房只需要客户端。
2. 将完整的 Alife.Function.Mindustry 文件夹放进 Alife 存储目录的 Plugins 中，再在「系统管理 → 插件环境」同步环境。保留 Resources 目录。
3. 在 Alife 打开「Mindustry 陪玩」模块界面，点击「选择游戏根目录」，选择包含 `Mindustry.exe` 的文件夹。没有找到游戏时，界面只会引导这一步。
4. 点击「安装 Mod」。模块会自动识别游戏实际使用的数据目录，把桥接安装到该目录下的 `mods`，生成令牌和 `alife-mindustry.properties`，并保存当前角色或全局配置。
5. 点击「启动并连接」，进入地图后等待状态卡片自动刷新。模块每 2 秒检测一次连接和房间状态。
6. 显示「已进入地图」后，对角色说「开启 Mindustry 陪玩」。陪玩开启后再说「看一下现在的关卡和库存，然后采 10 个铜运回核心」。结束游戏时说「关闭 Mindustry 陪玩」，操作工具会被立即卸载。

官方便携包可能把游戏和 Mod 数据分开放置。模块会依次检查游戏根目录下的 `data`、当前配置的数据目录、游戏根目录自身，以及 `%APPDATA%\Mindustry`。检测结果会分别显示「游戏位置」和「Mod 数据位置」。升级 Mod 时重新点击「重新安装 Mod」，然后重启游戏。

同队是默认模式。体验独立阵营可在启动客户端前设置 `ALIFE_MINDUSTRY_TEAM=2`，再进入 Passage 等具有该队伍核心的地图。团队编号必须在地图上存在核心。

如果桥接端口已被占用，在模块界面修改端口并重新自动安装，再重启游戏。不要只改配置文件，模块和 Mod 必须使用同一组端口与令牌。

如果模块界面显示「未连接」，先确认游戏窗口开着且已进入地图。若提示配置不一致，重新点击「安装 Mod」并保存底部配置。

## 新手流程

新手关可以让角色按顺序完成采铜、研究、加工、出兵和塔防。直接说：

> 查看当前关卡、库存和科技树，研究机械钻头、传送带、双管炮和铜墙。先采 10 铜，再建立一条铜产线，在核心附近建双管炮并补满铜弹。然后建硅冶炼炉和供电设施，送煤和沙加工硅，回收硅做一支陆军工厂并生产 Dagger。最后守着核心清掉接下来 3 波，安全完成后再汇报。

角色会先查询 `MindustryStatus` 和 `MindustryTech`，再调用采运、产线、建造、科技、加工、工厂和守卫工具。用户可以在过程中随时让角色停止。

## 专用服务器

无人值守或远程多人服务器使用服务端启动脚本。它会安装桥接并直接开启指定地图，玩家再通过「加入游戏」连接。

    & 'C:/你的Alife存储目录/Plugins/Alife.Function.Mindustry/Resources/Server/Start.ps1' -ServerJar 'C:/Mindustry/server-release.jar'

默认游戏端口 6567、桥接端口 18768。远程玩家连接服务器主机 IP。端口冲突时分别传入 `-GamePort` 和 `-Port`。退出服务器时在服务端窗口输入 exit。

## 自动陪玩和停止

- 查看、采运、建造、生产、进攻等工具只在陪玩开启且处于对局中时注册。开启失败时会说明是配置、游戏连接还是地图状态的问题。
- 一次性任务可以直接说「采 10 个铜运回核心」，或「在核心附近造一个双管炮并装弹」。角色会先查游戏状态，然后按任务反馈汇报。
- 要持续自主行动，请给出目标和结束条件，例如「自动陪玩，先建立铜补给，在核心附近布防，守到第 3 波确认清场后停止」。请同时说明是否允许主动开下一波。守卫期间，单位会给附近缺弹的物品炮塔补充核心中可用的弹药。
- 提前结束时，对角色说「停止自动陪玩，并取消当前任务」。停止自动陪玩和取消当前单位任务是两个操作。关闭 Mindustry 陪玩也会停止自主陪玩。已建成的设施和已交付的物资会保留。
- 独立阵营示例「针对 Passage 的敌方核心，先建设、备料、出兵，再进攻。游戏结算后停止」。独立阵营依赖地图上存在该队的核心。房间因没有玩家而暂停时，任务会等待恢复。

## 试用

- 「列出服务端任意三个关卡，并告诉我当前关卡和铜库存。」
- 「查一下当前状态，然后在核心附近找个位置造一面铜墙。完工后核对库存。」

本版支持两种模式。默认模式让 AI 和玩家共用一支队伍。设置 ALIFE_MINDUSTRY_TEAM 为有核心的队伍编号后，AI 可在 PvP 或多人地图中经营独立势力。

陪玩单位会使用游戏原生的寻路控制器。它可以移动、采集当前单位能力允许的地表矿或墙体矿，并把物资运回核心。MindustryStatus 会列出在线玩家、队伍、可见坐标、单位状态和最近的矿点。MindustryFind 可直接搜索全图可见的矿石、建筑或单位，并按离核心的距离排序，无需陪玩单位先移动过去。MindustrySurvey 返回单字符地形网格：小写字母是地表矿，大写字母是墙体矿，数字等符号是建筑，箭头是物流方向；建筑库存与 beam-node 连接另列在网格后。MindustrySupply 会从最近的可见地表矿点规划传送带路线，依次放置机械钻头和传送带，并等待核心库存真正增加后才报告成功。钻头必须覆盖矿床，出口方向必须对准传送带，资源才会入库。同一张地图上再次调用同种资源的产线工具，会按已记录的布局重建缺损格。换图会清除这份记录。MindustryGuard 会让单位到指定位置守卫，生命过低自动回核心。守卫时会优先给守卫点 20 格内的低弹量物品炮塔补充核心中可用的弹药，再返回守卫点。需要单独给工厂、加工建筑或炮塔送料时使用 MindustryFactoryFeed。任务有超时、取消、断线、换图和对局结束保护。

MindustryAutoplay 只在用户明确给出目标时开启。插件在空闲时每 15 秒把当前状态交给角色。清场后状态会给出下一波倒计时，角色可据此优先补防。守卫中若当前没有存活敌军且刷怪已结束，也会推送状态，让用户已授权的主动开波可以在守卫继续执行时进行。判定进度应读取已确认清场波次。它不会在地图切换或对局结束后继续执行旧目标。空服务器的自动暂停会让任务等待，不消耗任务时间。

## 短生存联调

使用独立的本机服务端。启动内置 Molten Lake 或 Triad 生存地图后，在服务器控制台设置胜利阈值、关闭自动开波并配置第一波飞行单位：

    js Vars.state.rules.winWave=2; Vars.state.rules.waveTimer=false; Vars.state.rules.spawns.clear(); var g=new SpawnGroup(UnitTypes.flare); g.begin=0; g.end=0; g.unitAmount=1; Vars.state.rules.spawns.add(g);

每个地图出怪口都可生成敌军。让 Alife 角色先采运铜、铺一条铜产线、建双管炮并装弹，然后主动开波和守卫。以游戏侧胜方回报作为验收。这里测试的是有限波次生存闭环。

独立阵营可以建造并配置陆军工厂。角色可读取工厂进度、电力、库存和阻塞状态。选择兵种后可用 MindustryFactoryFeed 从己方核心把所需物资运入工厂。工厂仍需要正常供电。Passage 联测中，真实 Alife 角色从已有工厂及预置核心库存开始，完成太阳能供电、供料、出兵和两座敌方核心的占领，最后由引擎判定 crux 获胜。另一次低库存联测从原版 100 铜开局，靠采运和冶炼建厂并生产 Dagger。真实 Alife 角色从状态读取目标，攻下两座敌方核心，游戏判定 crux 获胜。此轮曾保存并重启测试服以加载修复，也给角色提供了备料和供电提示。

为陆军工厂供电时，请给出兵口留空。工厂状态会显示出口坐标及障碍。v160.8 联测中，10 块普通太阳能板可供一座陆军工厂使用。

低库存时，可先以机械钻头和传送带建立煤产线，再采运沙和铅。用 MindustryFactoryFeed 给燃烧发电机送煤，并给硅冶炼炉送煤、沙。通过 MindustryStatus 检查运行状态，燃烧发电机显示 `active` 和正发电量才说明燃料与电网都已接通。使用 MindustryCollectSilicon 把产出的硅送回核心。电力节点可用 MindustryPowerLink 连到己方建筑。
